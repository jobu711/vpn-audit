# Task: WebSocket Real-Time Monitoring

## Description
Implement the WebSocket endpoint at `/ws/monitor` that streams real-time connection state from the ConnectionMonitor module to connected dashboard clients.

## Acceptance Criteria
- [ ] `WS /ws/monitor` endpoint in FastAPI
- [ ] Streams connection state updates from `ConnectionMonitor.stream()` at ~1Hz
- [ ] Handles multiple simultaneous WebSocket clients
- [ ] Graceful disconnect handling (client drops, server shutdown)
- [ ] JSON messages with interface info, latency, bandwidth, timestamps
- [ ] Integration test confirming WebSocket data flow

## Technical Details
- File: `backend/api/websocket.py` (or in `main.py`)
- Tests: `tests/test_websocket.py`
- Use FastAPI's built-in WebSocket support
- Async loop consuming `ConnectionMonitor.stream()` and broadcasting to clients
- Client management: set of active WebSocket connections
- Error handling: catch `WebSocketDisconnect`, remove client from set
