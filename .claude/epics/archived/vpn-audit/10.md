# Task: REST API Endpoints

## Description
Wire all core audit modules into FastAPI REST endpoints. Each endpoint invokes the corresponding module and returns structured JSON results. Includes a full-suite endpoint and status/results retrieval.

## Acceptance Criteria
- [ ] `POST /api/audit/leaks` — runs leak detection, returns AuditResult JSON
- [ ] `POST /api/audit/fingerprint` — runs traffic fingerprinting, returns AuditResult JSON
- [ ] `POST /api/audit/killswitch` — runs kill switch test, returns AuditResult JSON
- [ ] `POST /api/audit/full` — runs all modules, returns combined results
- [ ] `GET /api/status` — returns current connection status and interface info
- [ ] `GET /api/results` — returns latest stored audit results
- [ ] In-memory result storage (dict keyed by audit type)
- [ ] Integration tests for all endpoints

## Technical Details
- File: `backend/api/routes.py` (or directly in `main.py`)
- Tests: `tests/test_api.py`
- Use FastAPI's `TestClient` for integration tests
- Results stored in module-level dict, reset on app restart
- Proper HTTP status codes: 200 for success, 500 for module errors
- JSON response models using Pydantic for auto-documentation
