# Task: Web Dashboard

## Description
Build the single-page web dashboard with a two-panel CSS Grid layout. Left panel shows live connection monitoring via WebSocket. Right panel shows audit test cards with trigger buttons and results display.

## Acceptance Criteria
- [ ] `frontend/index.html` — two-panel grid layout, dark theme
- [ ] `frontend/css/style.css` — professional dark theme with status colors (green/red/yellow)
- [ ] `frontend/js/app.js` — WebSocket client, REST API calls, DOM updates
- [ ] Left panel: live connection status, IP info, latency/bandwidth gauges
- [ ] Right panel: audit test cards (Leaks, Fingerprint, Kill Switch, Full Audit) with trigger buttons
- [ ] Real-time updates from WebSocket reflected in left panel
- [ ] Test results displayed with pass/fail/warning styling
- [ ] Loading states while audits run
- [ ] FastAPI serves frontend as static files

## Technical Details
- Files: `frontend/index.html`, `frontend/css/style.css`, `frontend/js/app.js`
- CSS Grid: `grid-template-columns: 1fr 1fr` for two-panel layout
- WebSocket client: `new WebSocket("ws://localhost:8000/ws/monitor")`
- API calls via `fetch()` to POST endpoints for triggering audits
- Status colors: `--pass: #4caf50`, `--fail: #f44336`, `--warning: #ff9800`
- FastAPI static file mounting: `app.mount("/", StaticFiles(directory="frontend"))`
- Responsive: stack panels vertically on narrow screens

## Dependencies
- [ ] Task #10: REST API endpoints (for audit triggers)
- [ ] Task #4: WebSocket monitoring (for live data)
