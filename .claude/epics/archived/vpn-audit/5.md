# Task: Traffic Fingerprinting Module

## Description
Implement traffic fingerprinting in `backend/core/fingerprint.py`. Captures a sample of packets on the active interface, analyzes packet sizes, timing patterns, and port usage, then matches against known VPN protocol signatures.

## Acceptance Criteria
- [ ] `TrafficFingerprinter` class with `run()` method returning `AuditResult`
- [ ] Packet capture on active interface with configurable sample size/duration
- [ ] Protocol signature detection: WireGuard (UDP 51820), OpenVPN (UDP 1194 / TCP 443)
- [ ] Analysis of packet size distribution and timing patterns
- [ ] Report whether traffic is distinguishable from regular HTTPS
- [ ] Unit tests with mock packet data

## Technical Details
- File: `backend/core/fingerprint.py`
- Tests: `tests/test_fingerprint.py`
- Use Scapy `sniff()` with timeout for packet capture
- Build signature profiles: port ranges, packet size distributions, inter-arrival times
- Compare captured traffic against VPN protocol fingerprints
- Status: pass = traffic looks like normal HTTPS, fail = VPN protocol detectable, warning = inconclusive
