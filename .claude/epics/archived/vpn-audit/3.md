# Task: Leak Detection Module

## Description
Implement the DNS, WebRTC, and IPv6 leak detection module in `backend/core/leak_detect.py`. Uses Scapy for DNS packet sniffing, checks local interfaces for public IP exposure, and detects IPv6 leaks on non-tunnel interfaces.

## Acceptance Criteria
- [ ] `LeakDetector` class with `run()` method returning `AuditResult`
- [ ] DNS leak detection: sniff DNS packets, compare resolver against known VPN DNS IPs
- [ ] WebRTC leak check: query local network interfaces for unexpected public IPs
- [ ] IPv6 leak check: detect IPv6 connectivity on non-tunnel interfaces
- [ ] Each sub-check returns individual results aggregated into final AuditResult
- [ ] Unit tests covering pass, fail, and warning scenarios

## Technical Details
- File: `backend/core/leak_detect.py`
- Tests: `tests/test_leak_detect.py`
- Use Scapy `sniff()` with a timeout and BPF filter for DNS (port 53)
- Known Proton VPN DNS IPs to check against (configurable list)
- Use `psutil.net_if_addrs()` for interface enumeration
- IPv6 check: look for non-link-local IPv6 addresses on non-VPN interfaces
