# Add Windows interface classification tests

## Description

Add test coverage for the new shared interface classifier, specifically testing Windows NPF GUID resolution and VPN adapter description matching.

## Acceptance Criteria

- New test file `tests/test_interfaces.py` with tests for:
  - Linux/macOS prefix matching (tun0, wg0, proton0, tap0, utun3 → True)
  - Non-tunnel interfaces (eth0, wlan0 → False)
  - Case insensitivity (TUN0, Wg0 → True)
  - Windows NPF GUID that resolves to a VPN adapter → True
  - Windows NPF GUID that resolves to a physical adapter → False
  - Windows resolution failure → falls back to prefix matching
- All tests use mocking (no real hardware/platform dependency)
