# Create shared interface classification utility

## Description

Extract the duplicated `TUNNEL_INTERFACE_PREFIXES` constant and tunnel detection logic into a new shared module `backend/core/interfaces.py`. On Windows, resolve Scapy's NPF device GUIDs and psutil's adapter names to friendly names/descriptions using the Windows network API so VPN adapters (ProtonVPN, WireGuard, OpenVPN TAP) are correctly identified.

## Acceptance Criteria

- New file `backend/core/interfaces.py` with:
  - `TUNNEL_INTERFACE_PREFIXES` constant (single source of truth)
  - `is_tunnel_interface(iface: str) -> bool` function that:
    - On Linux/macOS: prefix-matches against known tunnel prefixes (existing behavior)
    - On Windows: resolves NPF GUIDs to friendly name/description and checks for VPN adapter keywords (e.g., "TAP-Windows", "WireGuard", "ProtonVPN", "Wintun")
- Cross-platform: uses `platform.system()` to branch logic
- Fallback: if resolution fails on Windows, falls back to prefix matching
