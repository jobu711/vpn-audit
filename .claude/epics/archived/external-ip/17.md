# Task 1: Core external IP module with caching and VPN masking check

## Description

Create `backend/core/external_ip.py` with an `ExternalIPChecker` class that:

1. Calls `http://ip-api.com/json` using `urllib.request` to fetch public IP, country, city, ISP, and org
2. Caches the response with a configurable TTL (default 30 seconds) to respect the 45 req/min rate limit
3. Compares the ISP/org against known VPN provider name patterns (default: Proton) to determine VPN masking status
4. Returns a dict: `{ip, country, city, isp, org, vpn_masked, status, timestamp}`
5. Provides a `run()` method returning an `AuditResult` for consistency with other core modules
6. Handles API errors gracefully — returns a dict with `status: "error"` and nulled fields on failure

## Files to Create/Modify

- **Create:** `backend/core/external_ip.py`

## Acceptance Criteria

- `ExternalIPChecker().lookup()` returns the expected dict shape
- Subsequent calls within TTL return cached data without making another HTTP request
- VPN masking detection correctly identifies known VPN ISP names
- API failures return error dict without raising exceptions
