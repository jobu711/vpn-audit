# Task 3: Frontend dashboard widget

## Description

Add an "External IP" widget to the left monitor panel of the dashboard:

1. **HTML** (`frontend/index.html`): Add a new `monitor-section` block above "Network Interfaces" with:

2. **JS** (`frontend/js/app.js`):

3. **CSS** (`frontend/css/style.css`): Minimal styling for the new widget, following existing card/section patterns
