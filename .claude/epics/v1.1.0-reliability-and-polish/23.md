# Task: Async audit execution and async monitor helpers

## Description

Wrap synchronous Scapy audit calls in `run_in_executor` so the FastAPI event loop stays responsive during long-running audits (up to 30s for fingerprinting/killswitch). Make `ConnectionMonitor.snapshot()` async by running blocking helpers (`estimate_bandwidth`, `measure_latency`, `get_routing_table`) via executor. This keeps the WebSocket monitor updating while audits are running.

## Acceptance Criteria

- [ ] `POST /api/audit/leaks` runs `LeakDetector().run()` via `run_in_executor(None, ...)`
- [ ] `POST /api/audit/fingerprint` runs `TrafficFingerprinter().run()` via `run_in_executor(None, ...)`
- [ ] `POST /api/audit/killswitch` runs `KillSwitchTester().run()` via `run_in_executor(None, ...)`
- [ ] `POST /api/audit/full` runs all three sequentially in executor (not parallel — Scapy not thread-safe)
- [ ] `ConnectionMonitor.snapshot()` becomes async, wrapping `estimate_bandwidth()`, `measure_latency()`, and `get_routing_table()` in `run_in_executor`
- [ ] `ConnectionMonitor.stream()` awaits the now-async `snapshot()`
- [ ] `time.sleep(0.5)` in `estimate_bandwidth()` remains (runs in executor thread, not event loop)
- [ ] Dashboard WebSocket monitor continues updating during audits (no freezing)
- [ ] No changes to API response format (backward-compatible)
- [ ] Existing tests continue to pass (update mocks if snapshot becomes async)

## Technical Details

### Files Modified
- `backend/api/routes.py` — Add `import asyncio`, wrap each audit `.run()` call in `await asyncio.get_event_loop().run_in_executor(None, lambda: ...)`
- `backend/core/monitor.py` — Make `snapshot()` async: wrap `estimate_bandwidth()`, `measure_latency()`, `get_routing_table()` in `await asyncio.get_event_loop().run_in_executor(None, ...)`. `get_interfaces()` is fast (psutil in-memory) so can stay synchronous. Update `stream()` to `await self.snapshot()`
- `backend/api/websocket.py` — No changes needed (`stream()` is already `async for`)
- `tests/test_monitor.py` — Update `TestSnapshot` to use `await` on `snapshot()`, mark as `@pytest.mark.asyncio`. Update `TestStream` if needed. `TestRun` may need update since `run()` calls `snapshot()` which is now async — either make `run()` async too or keep it synchronous with `asyncio.run()`
- `tests/test_api.py` — Tests should still pass since mock patches intercept before executor

### Key consideration: `run()` method
`ConnectionMonitor.run()` calls `self.snapshot()`. If `snapshot()` becomes async, `run()` either:
- Becomes async too (cleaner, but changes the interface)
- Uses `asyncio.get_event_loop().run_until_complete()` (breaks if loop is running)
- Best option: keep `run()` synchronous by having it call the blocking helpers directly (bypass async snapshot). The `run()` method is only called from `GET /api/status` which can also use executor wrapping.

### Routes.py pattern
```python
@router.post("/api/audit/leaks")
async def audit_leaks():
    loop = asyncio.get_event_loop()
    detector = LeakDetector()
    result = await loop.run_in_executor(None, detector.run)
    ...
```
