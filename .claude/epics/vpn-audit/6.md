# Task: Connection Monitoring Module

## Description
Implement real-time connection monitoring in `backend/core/monitor.py`. Polls network interfaces for IP addresses and status, tracks the routing table, measures latency and bandwidth, and emits state change events for WebSocket broadcast.

## Acceptance Criteria
- [ ] `ConnectionMonitor` class with `run()` returning `AuditResult` and async `stream()` generator
- [ ] Network interface polling via psutil: IP addresses, interface up/down status
- [ ] Routing table tracking via platform commands (`route print` on Windows, `ip route` on Linux)
- [ ] Latency measurement via ICMP ping
- [ ] Bandwidth estimation via throughput sampling
- [ ] State change events emitted as dicts for WebSocket consumption
- [ ] Unit tests for interface polling and state change detection

## Technical Details
- File: `backend/core/monitor.py`
- Tests: `tests/test_monitor.py`
- Use `psutil.net_if_addrs()` and `psutil.net_if_stats()` for interface info
- Platform-specific routing: `subprocess.run(["route", "print"])` on Windows, `["ip", "route"]` on Linux
- ICMP ping via `subprocess.run(["ping", ...])` with timeout
- `stream()` is an async generator yielding state dicts at ~1Hz
- State dict: `{interfaces: [...], routing: [...], latency_ms: float, bandwidth_mbps: float, timestamp: str}`
