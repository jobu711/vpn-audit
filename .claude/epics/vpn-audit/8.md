# Task: Kill Switch Audit Module

## Description
Implement kill switch testing in `backend/core/killswitch.py`. Monitors traffic on all interfaces during a controlled VPN disconnect window, detects non-tunnel traffic that escapes during reconnection, and measures time-to-block after disconnect.

## Acceptance Criteria
- [ ] `KillSwitchTester` class with `run()` method returning `AuditResult`
- [ ] Monitor all network interfaces for non-tunnel traffic during test window
- [ ] Detect leaked packets (traffic on non-VPN interfaces) during disconnect
- [ ] Measure time-to-block: how quickly the kill switch engages after VPN drops
- [ ] Configurable monitoring duration and test parameters
- [ ] Unit tests with simulated traffic scenarios

## Technical Details
- File: `backend/core/killswitch.py`
- Tests: `tests/test_killswitch.py`
- Use Scapy `sniff()` on all interfaces with async timeout
- VPN disconnect is manual (user-triggered) — tool only monitors and reports
- Track packets per interface, flag any non-tunnel traffic
- Time-to-block: measure interval between first non-tunnel packet and traffic cessation
- Status: pass = no leaked traffic, fail = packets escaped, warning = test inconclusive
