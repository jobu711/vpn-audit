# Project Vision

## Long-Term Direction

Become the go-to open-source VPN privacy verification tool — providing users with real, packet-level proof that their VPN is protecting them.

## Strategic Priorities

1. **Accuracy first** — Zero false negatives on leak detection; minimize false positives
2. **Cross-platform reliability** — Consistent behavior on Windows, Linux, macOS
3. **Multi-VPN support** — Expand beyond Proton VPN to all major providers
4. **User-friendly** — One-click audits, clear pass/fail results, no CLI expertise required

## Potential Expansions

- Scheduled/automated audit runs with historical reporting
- Support for additional VPN providers (NordVPN, Mullvad, ExpressVPN, etc.)
- Browser extension for WebRTC leak detection
- Export audit reports (PDF/JSON)
- Notification system for detected leaks
- Docker containerized deployment
